# Captures d'écran Scodoc

Ce dossier contient les captures d'écran affichées dans le dialogue de
levée d'anonymat Scodoc. Elles guident l'utilisateur pour récupérer la table
des étudiants depuis Scodoc.

Les fichiers sont des **placeholders vides (1x1 px)**. Remplacez-les par vos
propres captures d'écran, en conservant les noms suivants :

- `Scodoc_student_list.png` — menu de téléchargement de la table étudiants
  (page principale du semestre).

Ces images sont volontairement séparées du code pour pouvoir être mises à
jour facilement : Scodoc est régulièrement remis à jour, l'interface peut
changer. Il suffit de remplacer le PNG ici (même nom) et de relancer
l'application.

Les images sont incluses dans le paquet (cf. `package-data` dans
`pyproject.toml`).
